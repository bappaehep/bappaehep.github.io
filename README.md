# Bappaditya Mondal — Academic Portfolio

A responsive academic portfolio website for Bappaditya Mondal, PhD researcher in experimental nuclear physics and member of the STAR Collaboration at RHIC.

## Files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year
- `CV.pdf` — add your final CV PDF here

## GitHub Pages

1. Create a GitHub repository, e.g. `bappaditya-mondal.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `CV.pdf`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`

## Important edits before publishing

Replace the placeholder profile links in the Contact section with your actual:
- Google Scholar
- ORCID
- INSPIRE-HEP
- GitHub

Add your actual CV as `CV.pdf` in the repository root.
